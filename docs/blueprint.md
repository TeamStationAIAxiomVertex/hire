# **App Name**: TeamStation AI Nearshore IT Talent

## Core Features:

- Technology Data Import: Import the canonical dataset of 87 technologies from /data/tech.ts.
- Page Generation: Automatically generate 85+ 'Hire by Technology' pages using scripts/generate-content.ts.
- SEO Optimization: Optimize each generated page for search engines based on the technology.
- Google Analytics Integration: Implement Google Analytics 4 (GA4) for tracking user behavior.
- Static Page Hosting: Host the static Next.js site on Firebase Hosting with custom domain hire.teamstation.dev.
- Technology Detail Display: Display detailed information for each technology on its dedicated page.
- Content Suggestions: Suggest appropriate content and keywords to place on a hire by technology page. The suggestions will act as a tool that will improve user conversion.

## Style Guidelines:

- Primary color: Deep blue (#293B5F) to convey professionalism and trust, aligning with the serious nature of hiring.
- Background color: Light gray (#F0F4F8), a subtle and unobtrusive backdrop.
- Accent color: Soft purple (#A992D5) used in call-to-actions to add interest and aid findability, standing out against the more muted blue.
- Headline font: 'Space Grotesk' (sans-serif) for a tech-forward and modern feel.
- Body font: 'Inter' (sans-serif) ensuring readability and a clean design, complementing the header font for clarity.
- Implement a clean and responsive layout to ensure usability across devices.
- Employ minimalist icons to represent technology categories or related concepts.
