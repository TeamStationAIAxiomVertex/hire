## How to Download Your Project

You can download a complete archive of your project at any time. The workspace includes a recovery script that packages your application source code into a single compressed file (`.tar.gz`).

This script is safe to run and will automatically exclude heavy directories like `node_modules` and `.next`, keeping the download small.

**To create the archive:**

1.  Open the terminal.
2.  Run the following command:

    ```bash
    bash ./recover_workspace.sh
    ```

3.  After the script completes, a new file (e.g., `teamstation-ai-full-....tar.gz`) will appear in your file explorer.
4.  Right-click on this new file and select **Download**.
